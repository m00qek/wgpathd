# Tutorials

Tutorials are lessons. Each takes you step by step through a complete piece of work, so you learn by doing it.

---

- [Your First Failover](first-failover.md) - Configure wgpathd on a hub and two spokes in a lab of OpenWrt containers, watch both spokes go direct, then cut the direct path and watch the relay carry the traffic.
- [Developer Onboarding](dev-onboarding.md) - Run the test suite, explore the decision core's tests, build the package and check it installs on a fresh OpenWrt.

Once you have done the lab, set up wgpathd on real routers with the operator [how-to guides](../how-to/index.md), starting with [preparing the WireGuard substrate](../how-to/prepare-substrate.md).
